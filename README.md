# 알잘딱골 👨‍💻

> **알고리즘을 잘 알아서 딱 골라 푸는 그날까지!**

SSAFY에서 함께 알고리즘과 코딩 테스트를 공부하는 스터디입니다.

매주 정해진 문제를 함께 풀고, 서로의 접근 방식과 풀이 과정을 공유하며
단순히 문제를 푸는 것을 넘어 **풀이를 설명하고 비교할 수 있는 능력**을 기르는 것을 목표로 합니다.

---

## 📚 What We Do

* 매주 공통 알고리즘 문제 풀이
* 개인 브랜치를 통한 풀이 코드 관리
* Pull Request를 통한 풀이 기록 및 공유
* 서로 다른 풀이 방법과 시간·공간 복잡도 비교
* 오프라인 모임을 통한 코드 리뷰 및 풀이 토론
* 해결하지 못한 문제도 끝까지 이해하고 학습 과정 기록

---

## 📦 Repository

### [SSAFY Algorithm Study](https://github.com/aljaldakgol/ssafy-algorithm-study)

알고리즘 문제 풀이와 스터디 기록을 관리하는 메인 Repository입니다.

* Branch Convention
* Commit Convention
* Pull Request Convention
* 코드 작성 및 제출 규칙
